# 前端设计系统

## 1. 定位

前端参考 WorkCove 的视觉方法，但服务对象不是研发工作台，而是真人出镜视频创作。

目标观感：

> macOS 原生工作空间的空间关系 + 视频创作工具的高信息密度。

需要保留：

- 克制的白色画布
- 清晰的层级
- 紧凑但可读的排版
- 语义化颜色
- 稳定的工具栏和面板尺寸
- 少量材质和阴影
- 真实状态反馈

不需要：

- 通用后台模板的卡片堆叠
- 大面积渐变和大色块
- 营销式大标题
- 假窗口按钮
- emoji 功能图标
- 过度圆角和悬浮卡片

## 2. 设计令牌

唯一的视觉数值来源：

```text
frametalk-web/src/styles/tokens.css
```

业务组件只能使用语义变量：

```css
var(--text)
var(--text-muted)
var(--canvas)
var(--canvas-raised)
var(--surface-inset)
var(--system-blue)
var(--radius-control)
var(--space-4)
var(--font-body)
```

禁止：

- 在业务组件中写新的十六进制颜色
- 写死第二套字体栈
- 写死阴影和圆角
- 使用负字距
- 使用小于 11px 的业务文字

## 3. 字体

默认字体：

```css
system-ui, -apple-system, BlinkMacSystemFont, "SF Pro Text",
"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif
```

字号：

| 令牌 | 值 | 用途 |
| --- | ---: | --- |
| `--font-caption` | 11px | 元信息、辅助说明 |
| `--font-body` | 13px | 正文、表单、按钮 |
| `--font-title` | 15px | 面板标题 |
| `--font-metric` | 22px | 指标数字 |
| `--font-display` | 28px | 页面主标题 |

时间码、帧数、ID、路径使用 `--font-mono` 和等宽数字。

## 4. 颜色

语义色：

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 主操作 | `#007AFF` | `#0A84FF` |
| 错误 | `#FF3B30` | `#FF453A` |
| 警告 | `#FF9500` | `#FF9F0A` |
| 成功 | `#34C759` | `#30D158` |
| 中性 | `#8E8E93` | `#98989D` |

业务组件使用：

```css
var(--system-blue)
var(--system-red)
var(--system-orange)
var(--system-green)
```

颜色必须同时配合文字或图标，不能单独表达状态。

## 5. 页面骨架

桌面端：

```text
┌──────────────────────────────────────────────────┐
│ 46px 顶栏                                        │
├──────────────┬───────────────────────────────────┤
│ 216px 侧栏    │ 内容区                             │
└──────────────┴───────────────────────────────────┘
```

顶栏包含：

- 品牌
- 当前项目切换
- 全局搜索
- 运行中任务
- 用户入口

侧栏包含：

- 项目概览
- 脚本工作区
- 素材库
- 渲染队列
- 设置

不使用 WorkCove 的交通灯，除非应用未来真的运行在桌面壳中。

## 6. 项目工作区

项目页使用三栏加时间轴：

```text
┌──────────────┬──────────────────┬──────────────┐
│ 脚本/逐字稿   │ 视频预览          │ 素材/属性     │
│              │                  │              │
├──────────────┴──────────────────┴──────────────┤
│ 时间轴与字幕轨                                  │
└────────────────────────────────────────────────┘
```

桌面端建议：

- 左栏 320px
- 右栏 280px
- 中间自适应
- 时间轴高度 220 到 280px
- 所有分栏可折叠

移动端：

- 不使用三栏压缩
- 切换为“脚本 / 预览 / 素材 / 时间轴”分段视图
- 底部任务状态保持可见

## 7. 视觉表面

使用：

- 页面背景：`--canvas`
- 内容面板：`--canvas-raised`
- 工具栏和侧栏：`--material` 或 `--sidebar`
- 二级控件：`--surface-inset`
- 视频预览：专用深色画布

限制：

- 页面区块使用平面布局，不把所有内容装进卡片
- 卡片只用于重复项目、弹窗和真正独立的工具面板
- 列表分隔线和悬停背景铺满整行
- 列表容器不设左右内边距，由行承担

## 8. 控件

### 8.1 基础组件

所有基础组件放在：

```text
components/ui/
```

首批组件：

```text
UiButton
UiInput
UiTextarea
UiFormField
UiSelect
UiCombobox
UiDialog
UiConfirmDialog
UiSegmentedControl
UiSearchInput
UiPagination
UiSpinner
UiStatusDot
```

规则：

- 一个操作区只允许一个 `primary`
- 删除和破坏操作使用 `danger` 或 `danger-ghost`
- 下拉、弹窗和分段控件使用自有实现
- 图标按钮必须有 `aria-label` 和 hover 提示
- 纯装饰图标设置 `aria-hidden="true"`
- 业务页面不重写控件高度、圆角和阴影

### 8.2 控件尺寸

| 尺寸 | 高度 | 用途 |
| --- | ---: | --- |
| `sm` | 20px | 行内操作 |
| `regular` | 24px | 默认控件 |
| `lg` | 28px | 工具栏和弹窗 |

触控设备上的独立操作目标不小于 44px。

## 9. 间距、圆角和阴影

间距只使用 4px 网格：

```text
4 / 8 / 12 / 16 / 20 / 24 / 32
```

圆角：

| 元素 | 值 |
| --- | ---: |
| 标签 | 4px |
| 按钮和输入框 | 6px |
| 面板和菜单 | 10px |
| 弹窗 | 12px |

阴影只在需要表达层级时使用：

- 控件使用 `--shadow-control`
- 面板使用 `--shadow-panel`
- 菜单使用 `--shadow-popover`
- 弹窗使用 `--window-shadow`

不给页面中的每个区块加阴影和描边。

## 10. 图标

统一使用 `@lucide/vue`。

- 常规图标 16px
- 工具栏图标 18 到 20px
- 空状态图标 28 到 32px
- 普通操作使用 `--icon`
- 悬停使用 `--icon-hover`
- 删除图标始终使用 `--system-red`
- 不用 emoji 代替功能图标

## 11. 视频和音频界面

视频预览区是唯一允许大面积深色的业务区域。

需要：

- 固定宽高比
- 播放、暂停、逐帧、音量使用图标按钮
- 时间码使用等宽字体
- 字幕安全区可见但默认低干扰
- 人像框选和裁切区域可切换显示
- 素材替换后只更新局部预览

不做：

- 装饰性光效
- 动态粒子
- 与视频内容无关的渐变背景

## 12. 响应式

断点：

| 宽度 | 行为 |
| --- | --- |
| `>= 1024px` | 桌面三栏 |
| `760px - 1023px` | 侧栏折叠，双栏 |
| `< 760px` | 单栏分段视图 |
| `< 520px` | 表单上下排布，弹窗贴边 |

必须保证：

- 页面无横向滚动
- 长文本不遮挡相邻控件
- 固定格式控件不会因加载文字改变尺寸
- 移动端所有核心操作可达

## 13. 状态与反馈

每个页面必须实现：

- 加载态
- 空状态
- 错误态
- 成功反馈
- 禁用态
- 长文本状态

任务状态：

```text
queued
running
succeeded
failed
cancelled
```

运行中显示阶段和进度。失败说明原因和下一步动作，不只显示“操作失败”。

## 14. 可访问性

- 键盘可以到达全部交互控件
- 弹窗焦点进入、Tab 循环、Esc 关闭和焦点返回完整
- 下拉支持方向键、Home、End、Enter 和 Space
- 焦点样式清晰
- 颜色不是状态的唯一表达
- 业务文字不小于 11px
- 尊重 `prefers-reduced-motion`

## 15. 数据流

```text
View
  -> business component
  -> Pinia store
  -> api/<domain>.ts
  -> API client
  -> Java API
```

规则：

- View 组合页面，不直接 `fetch`
- Store 负责缓存、加载状态和业务动作
- API 模块负责请求和响应类型
- UI 组件不接触 Store 或 API
- 业务类型从 OpenAPI 生成或位于 `types/`

## 16. 安全

- 不在前端保存内部能力 Token
- 不拼本机绝对路径
- 媒体使用 Java 鉴权流接口
- 上传使用 Java 分片接口
- 错误提示不泄露堆栈和服务器路径
- 用户输入在渲染前按场景转义

## 17. 实现顺序

1. 设计令牌、全局样式和应用壳
2. UiButton、UiInput、UiFormField
3. UiSelect、UiDialog、任务状态组件
4. 项目列表和项目工作台
5. 脚本编辑器
6. 视频预览和逐字稿时间轴
7. 素材选择器
8. 渲染队列和导出页
